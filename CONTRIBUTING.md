# Contributing to SwarmPulse

Thank you for your interest in improving SwarmPulse!

## Development Setup
1. Fork the repo
2. Create a virtualenv: `python -m venv venv`
3. Install dev dependencies: `pip install -e .[dev]`

## Guidelines
* Use type hints for all new functions.
* Ensure all tests pass before submitting a PR.
* Update the README if you add new game engine drivers.

## Bug Reports
Use the GitHub issue tracker to report bugs. Please include logs and the game engine target version.
